Algorithmic Step Deconstruction

Greedy Choice
1
Distance Table & Base Anchor

Initializes all distances to infinity (INF) except dist[src] = 0. Min-heap is seeded with the origin pair.

2
Greedy Min-Heap Extraction

Continually extracts vertex u having minimum provisional distance. Stale entries with higher costs are skipped instantly.

3
Edge Relaxation Invariant

For each incident edge (u, v), checks if dist[u] + w < dist[v]. If satisfied, updates distance and pushes new candidate to queue.

Time Complexity Optimal
O((V + E) log V) V heap extractions + at most E decrease-key equivalent pushes.
Auxiliary Space Memory
O(V + E) Stores graph representation and at most E items in the priority queue.
